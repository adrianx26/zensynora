    ZenSynora Documentation¶

    Index created 2026-10-13 for v0.7.0, updated for v0.7.1. Start with the project README for installation and a tour.

    Using ZenSynora¶

    Guide What it covers
    Web UI guide Chat channels with several agents, agent-to-agent activity, Models (switch, rotate, your own providers), Jobs, Backups, the Telegram bot in Settings → Channels
    Knowledge base Note format (tags, aliases, metadata, facts, links), search syntax, what agents see, CLI, .trash, .bmignore
    Telegram bot Set up the Telegram bot, allow users, commands, @agent messages, reminders, knowledge, troubleshooting
    Updating zensynora update, rollback, data and program-folder backups, how updates stay safe
    Medic & Doctor zensynora doctor, the Doctor page, medic tools, integrity and recovery, self-update proposals and learning
    Choosing an LLM Which local model for which hardware; llama.cpp / Ollama / LM Studio setup
    Web UI Pages, what each one talks to, developing the front end
    Agent catalog The 137 built-in agent profiles
    Agent swarms Parallel, sequential, hierarchical and voting swarms
    Scheduler features Reliable scheduled jobs: validation, retries, checkpoints
    Task timer Progress and time tracking for long tasks
    Execution backends Run commands locally, in Docker, over SSH or in WSL2
    Web scraping (Scrapling) Anti-bot scraping for agents
    External skills Importing skills from other ecosystems
    NewTech agent AI-news monitoring and roadmap proposals
