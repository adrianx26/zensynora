3. A chat message, end to end

What happens when you type in the Web UI (Telegram and the terminal follow the same path from `Agent` onwards).

sequenceDiagram autonumber actor U as You participant UI as Web UI (React) participant WS as web/api.py<br/>WebSocket /ws/chat/{agent} participant A as Agent.stream_think participant R as router + medic loop guard participant C as context_builder participant M as memory.py participant K as knowledge/ participant P as provider.py participant T as tools/ U->>UI: type a message UI->>WS: send text WS->>WS: quota + optional MFA check WS->>A: stream_think(text, user="webui") A->>R: start task timer, depth + loop limits A->>M: add(user message) A->>C: build context C->>M: get_history() (flushes buffered turns) C->>K: search notes for relevant knowledge C-->>A: system prompt + history + knowledge A->>P: chat(messages, stream=True) P-->>A: token stream (+ tool calls) A-->>WS: tokens WS-->>UI: __STREAM_START__ … tokens … __STREAM_END__ opt the model asked for tools A->>T: execute (parallel when independent) T-->>A: results A->>P: chat again with tool results P-->>A: final answer stream A-->>WS: tokens end A->>M: add(assistant reply) UI-->>U: rendered reply

9. Safe updates

`zensynora update` (`updater/`, added in 0.6.0). Steps 1–9 never touch the running version; any failure undoes the completed steps in reverse order.

flowchart TD s1["1 Preflight<br/>Python, disk space, service state"] --> s2["2 Fetch<br/>GitHub, folder or archive"] s2 --> s3["3 Hand-off<br/>newer updater takes over"] s3 --> s4["4 Back up ~/.myclaw + .env"] s4 --> s5["5 Carry over .env, data/"] s5 --> s6["6 Build side by side<br/>venv · packages · extras · Web UI"] s6 --> s7["7 Verify<br/>imports new code, loads YOUR config"] s7 --> s8["8 Stop service"] s8 --> s9["9 Data migrations"] s9 --> s10["10 Activate<br/>atomic symlink switch"] s10 --> s11["11 Start service, confirm up"] s11 --> s12(["12 Record, prune old releases"]) s2 & s6 & s7 & s9 & s10 & s11 -. "failure" .-> rb["Roll back<br/>old version stays active,<br/>data restored if migrated"]
