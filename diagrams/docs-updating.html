What happens during an update

flowchart TD start["Update or approved Doctor reinstall"] --> pre["Preflight, fetch, updater handoff"] pre --> data["Mandatory user-data backup"] data --> mode{"Program archive enabled?"} mode -- no --> skip["SKIPPED: program archive"] mode -- yes --> pause{"Interactive mode?"} pause -- no --> archive["Create program archive"] pause -- yes --> decision{"WAITING: user decision"} decision -- Continue --> archive decision -- Skip --> skip decision -- Abort --> rollback["Roll back completed steps"] archive --> build["Carry user files, build, verify"] skip --> build build --> activate["Stop service, migrate, activate"] activate --> check["Verify or restore user data"] check --> finish["Start service, record history, prune"] build & activate & check & finish -. failure .-> rollback rollback --> outcome{"Recovery succeeded?"} outcome -- yes --> recovered["ROLLED-BACK: inspect outcomes"] outcome -- no --> failed["ROLLBACK-FAILED: preserve backups and repair"] finish --> ok["OK: restart into installed release"] pre & data & archive & build & activate & check & finish -. events .-> logs[("Timestamped colored progress and logs")]
